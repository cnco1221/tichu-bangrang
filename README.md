# 티츄 (Tichu) 실시간 4인 웹게임 v2

Node.js + Socket.IO 서버, 바닐라 JS 클라이언트. GitHub + Render 배포 구조.

## 로컬 실행

```bash
npm install
npm start
# http://localhost:3000
```

## 폴더 구조

```
server.js           Express + Socket.IO 서버, 방/관전/투표/회원가입/관리자/랭킹 이벤트 처리
firebase.js          Firebase Admin SDK 초기화(환경변수 없으면 자동 비활성화)
accounts.js          회원가입/로그인/관리자/랭킹 로직(Firestore 연동)
game/deck.js         56장 덱 생성 (참새/개/불사조/용 포함), 점수 계산
game/combos.js       족보 판별 + 강약 비교 + 참새 요청 강제 이행 판정
game/Room.js         게임 상태 머신 전체 (준비→라지티츄→교환→플레이→정산), 타이머/재접속/등급전
public/               클라이언트 (index.html, style.css, client.js)
tests/test_sim.js     봇 자동 플레이 스모크 테스트 (여러 라운드)
tests/test_rules.js   신규 규칙 단위 테스트 (폭탄 인터럽트, 참새 강제, 봉황 동적파워, 등급전 등)
```

테스트: `node tests/test_sim.js` / `node tests/test_rules.js`

## 반영된 규칙 (합의된 내용대로)

- **덱**: 옥/검/탑/별 4수트 × 2~A + 참새(1)/개/불사조/용 = 56장
- **참새 카드**: 좌상단·우하단에 숫자 "1", 중앙에 참새 아이콘
- **라지티츄**(구 그랜드티츄): 8장 받은 시점에만 콜 가능, 그때 패스하면 이후 절대 불가. 성공 +200 / 실패 -200
- **스몰티츄**(구 티츄): 첫 카드를 내기 전까지 언제든 콜 가능, 한 장이라도 내면 이후 불가. 성공 +100 / 실패 -100
  - 성공 기준: **전체 4명 중 1등으로 손을 털었을 때만** 성공 (같은 편이 먼저 나가도 실패)
- **카드 교환**: 다음 사람/파트너/이전 사람에게 1장씩 동시 교환, 참새 든 사람이 첫 리드
- **기본 족보 6종**: 싱글/페어/트리플/연속페어(계단)/스트레이트/풀하우스 — 선이 낸 것과 **같은 족보·같은 장수**만 따라갈 수 있음
- **폭탄**: 포카드, 스트레이트플러시(같은 무늬 5장+). **자기 차례가 아니어도 언제든 인터럽트 가능하지만, 트릭에 카드가 최소 1장 나와 있어야 함** (완전히 빈 리드 상태에서는 불가). 폭탄으로 이기면 낸 사람이 직접 카드를 가져감
- **참새(1) 요청 강제**: 참새를 콜하며 숫자를 요청하면, 이후 순서상 그 카드를 갖고 있고 **낼 수 있는 상황(싱글로 이기기/포카드봄/스트레이트 완성 등)이면 반드시 내야 함**. 못 내는 사람을 건너뛰고 다음 사람에게도 계속 적용됨. 스트레이트로 참새를 콜한 경우, 한 장이 모자라면 불사조로 메워서라도 내야 함
- **봉황(불사조)**: 페어/트리플/풀하우스/스트레이트/계단의 조커로 사용 가능(애매하면 더 유리한 쪽으로 인정, 예: 풀하우스 2+2 상황에서 더 높은 숫자를 트리플로). 싱글로 낼 경우 **직전 카드보다 +0.5**로 취급 (K 다음이면 13.5 → A로 밟힘, A 다음이면 14.5 → 용만 이김). 점수는 **-25점**
- **용(龍)**: 싱글 전용, 25점, 봉황·기본족보로는 못 이김(폭탄 제외). **용으로 트릭을 이기면 카드 전부(용 포함)를 상대팀 중 한 명에게 반드시 줘야 함**(자기 팀은 못 가짐)
- **개**: 값 0(참새보다 낮음), **리드의 첫 카드로만** 낼 수 있고, 내는 즉시 트릭이 종료되며 **용/폭탄으로도 막을 수 없음**. 파트너에게 선이 넘어가고, 파트너가 이미 아웃이면 다음 순서 → 그마저 아웃이면 본인에게
- **트릭 종료**: 마지막으로 낸 사람 기준 나머지 전원이 연속 패스하면 그 사람이 카드를 모두 가져감. 중간에 누가 다시 내면 패스했던 사람도 다시 낼지 패스할지 선택 가능(패스 카운트 초기화)
- **라운드 종료 정산**: 3명이 아웃되면 (꼴찌 트릭→1등, 꼴찌 손패→상대팀) 처리 후 점수 집계(5=5점, 10·K=10점, 용=25점, 봉황=-25점). 1·2등이 같은 팀이면 더블윈으로 집계 없이 고정 200점
- **목표 점수**: 1000점 선취 팀 승리

## 반영된 시스템 기능

- **닉네임 입력**(최대 10자) → 방 만들기/참가
- **준비(레디) 시스템**: 4자리가 다 차도 전원 준비 완료해야 시작 가능
- **관전 기능**: 자리가 없으면 자동으로 관전자 입장. 로비에서 관전자 수 표시 + 클릭하면 닉네임 목록 토스트로 확인. 게임 진행 중이 아니면 관전자가 빈 좌석에 "이 자리에 앉기"로 참여 가능
- **탈주 처리**: 게임 진행 중(라지티츄~정산) 플레이어가 접속 끊으면 즉시 게임 무효 + 로비로 리셋(점수 초기화)
- **게임 취소 투표**: 메뉴 → "게임 취소 투표 시작" → 나머지 전원이 동의하면 페널티 없이 게임 취소, 한 명이라도 거절하면 투표 무산
- **턴 타임리밋 30초**: 초과 시 자동 처리 — 리드 상황이면 가장 낮은 싱글 자동 제출, 참새 요청을 이행해야 하는 상황이면 해당 카드 자동 제출, 그 외엔 자동 패스. 매 타임아웃마다 "잠수 카운트" +1, **3회 누적 시 게임 무효 처리**. 잠수 카운트는 게임이 끝나면(정상 종료/무효 처리 모두) 0으로 초기화
- **UI**: 동(상대)·서(상대)·남(나, 고정)·북(아군) 나침반 배치, 진행 방향은 반시계(남→동→북→서). 텍스트 태그("나"/"아군"/"상대")로 표기, 닉네임은 그 아래 별도 표시. 화면 하단 내 카드, 카드 바로 위 스몰티츄/패스/내기 버튼. 우측 상단 메뉴(방 나가기·게임 취소 투표), 우측 하단 채팅 버튼(패널 토글)
- **규칙 기반 봇**: 로비에서 빈 자리에 "봇 추가"로 채울 수 있음. 리드는 최저싱글, 따라갈 땐 이길 수 있는 가장 작은 카드(용 제외), 참새 요청은 최우선 이행 — 단순 휴리스틱이라 티츄콜/패추론/파트너 배려는 안 함. 더 똑똑하게 하려면 Claude API 같은 LLM 연동이 필요(미착수)

## 회원가입 / 관리자모드 / 랭킹 / 등급전 (Firebase 연동)

**Firebase 설정 방법** (`firebase.js`가 아래 3개 환경변수를 읽어요):
1. [console.firebase.google.com](https://console.firebase.google.com) → 프로젝트 생성 → "Firestore Database" 활성화(프로덕션 모드, 리전은 asia-northeast3 추천)
2. 프로젝트 설정(톱니바퀴) → "서비스 계정" 탭 → "새 비공개 키 생성" → JSON 다운로드 (이 파일은 절대 GitHub에 올리지 말 것)
3. Render → 해당 서비스 → Environment 탭에 아래 3개 추가
   - `FIREBASE_PROJECT_ID` = JSON의 `project_id`
   - `FIREBASE_CLIENT_EMAIL` = JSON의 `client_email`
   - `FIREBASE_PRIVATE_KEY` = JSON의 `private_key` (따옴표 포함 통째로, 안의 `\n`은 그대로 붙여넣기)
   - 로컬 테스트는 `.env` 파일에 같은 값 넣기(`.gitignore`에 이미 포함됨)
4. 이 환경변수가 없으면 회원가입/관리자/랭킹 기능은 "아직 설정 안 됨" 에러만 반환하고, 게임 자체(방 만들기/플레이)는 평소대로 동작해요.

**회원가입/승인**: 랜딩 화면 "회원가입"(이름·닉네임·비밀번호) → 관리자가 승인해야 로그인 가능. 이름은 관리자만 볼 수 있고 다른 곳엔 안 보여요.

**관리자모드**: 랜딩 화면 좌측 상단 "관리자모드" 버튼 → 비밀번호 입력(초기값 `159`) → 멤버 관리 / 멤버 승인 / 비밀번호 변경 3개 탭.

**랭킹**: 랜딩 화면 하단 "🏆 랭킹" 버튼 → 랭킹 탭(승률순, 등급전 0회면 "X") / 명예의 전당 탭(시즌제는 추후 추가 예정, 지금은 안내 문구만).

**등급전**: 로비에서 "등급전 켜기" → 지정석 자동 해제+잠금(무조건 랜덤 팀), 1000점 게임, 종료 시 로그인한 회원 좌석에 한해 승/패가 Firestore에 자동 기록됨(비회원 게스트 좌석은 기록 안 됨).

## 아직 안 한 것 (다음에 진행)

- **상점 시스템**: 닉네임 효과, 이모티콘 구매 — 지금 당장 진행 안 함(합의됨)
- **시즌제 명예의 전당**: 등급전 랭킹은 되지만 시즌 구분/시즌별 1위 기록은 아직. 지금은 "추후 추가 예정" 안내만 뜸(합의됨)
- **AI(LLM) 대전**: 지금 봇은 규칙 기반. 상대 패 추론이나 전략적 판단까지 하려면 Claude API를 붙여야 함
